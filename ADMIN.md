# Owner administration

This is a GitHub Pages static website. Visitors have view-only access: there are no public edit, delete, remove or change controls.

The owner manages all changes securely through the private GitHub account and repository permissions:

1. Sign in to GitHub as `kaziriazulhasan`.
2. Open `kaziriazulhasan.github.io`.
3. Edit or replace website files, then commit changes.
4. GitHub Pages deploys the update automatically.

Never put a password, API key, NID, TIN or other sensitive personal information in public website files. A real login-based admin dashboard requires a server/database; it cannot be securely implemented with static GitHub Pages alone.
